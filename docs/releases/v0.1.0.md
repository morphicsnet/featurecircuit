# FeatureCircuit Protocol v0.1.0

Release date: 2026-03-08

## Highlights
- Consolidated `superposition-demo` and `superposition-solver1` into `featurecircuit-protocol`.
- Established canonical artifact pipeline:
  - `ActivationBatch`
  - `FeatureSpaceDescriptor`
  - `FeatureEventStream`
  - `RelationArtifact`
  - `StructureArtifact`
  - `CandidateSetArtifact`
  - `CircuitSnapshotArtifact`
  - `ScoreBundleArtifact`
- Added deterministic identity helpers and event/member key composition.
- Added protocol manifest lineage/export-profile declarations and compatibility checks.
- Migrated demo internals to canonical `py_nsi` API surface.
- Added release automation:
  - preflight gate
  - artifact verification gate
  - blocker gate
  - scripted tag workflow
  - release GitHub Actions workflow

## Compatibility
- `py_nsi.compat` remains available for this consolidation release only.
- Planned removal after this release line; migrate to canonical `py_nsi` classes.
